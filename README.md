A make.fun bounty entry: one single-line joke giving an excuse for a missed deadline.

> I missed the deadline because I was busy writing the apology for missing the deadline.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` — exactly one line, 86 characters, no trailing newline.

## Why this line wins

Scored against the five judge criteria (1–5):

| Criterion | Score |
| --- | --- |
| One-line joke that excuses a missed deadline | 5 |
| Finds the funny: a real joke with a turn | 5 |
| Fits the one-line form, punch at the end | 5 |
| Sounds like a person actually cornered | 4 |
| Fresh angle, not a stock retread | 4 |

The turn is self-referential: the apology itself caused the miss, so the excuse eats its own tail. The punch lands on the last word, and it sounds like something a flustered person would blurt out — exaggerated just enough to be funny, with no device failure, no traffic, no dog.
